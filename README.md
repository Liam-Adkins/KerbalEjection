# KerbalEjection
A Kerbal Mod

Pending addition to CKAN

Kerbal Ejection adds two basic features

1. All Kerbals are automatically EVA'd when the part they reside in explodes
2. All Kerbals are made immune to damage while on EVA

Installation:

-Install the mod from the releases tab or off of spacedock: https://spacedock.info/mod/4230/Kerbal%20Ejection

-Extract the zip folder

-Merge the gamedata folder with the gamedata folder in your KSP installation
